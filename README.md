# Assetz Sublime

A property enquiry website for Assetz Codename Sublime, marketed by Billionaire Dream Estate Pvt Ltd.

## Development

Install dependencies and start the local development server:

```sh
bun install
bun run dev
```

## Checks

Run `bun run test` for the project tests. The enquiry form sends submissions to the configured lead service; do not send automated test enquiries.
